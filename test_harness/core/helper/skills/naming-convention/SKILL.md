description: Team naming rules for files in the notes-app Expo project (stores, screens, hooks). Use when asked to name or rename a file or module.
---
Our team convention for the Expo notes-app:
- zustand store files are named `<feature>.store.js` (example: `checkout.store.js`), one store per file.
- screens are `<Name>Screen.js` (PascalCase); hooks are `use<Name>.js`.
Answer with the exact file name only, then one line saying which rule applied.
