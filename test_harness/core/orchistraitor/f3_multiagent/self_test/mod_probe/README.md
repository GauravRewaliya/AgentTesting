# mod_probe (2026-11-20)
A 12-line mod that answers the `Agent` tool itself. It proved that a MOD loads under `claude -p --plugin-dir` and that a `tool.call` hook can return a REAL tool result (about $0.003 with haiku).
Free check: `claude plugin validate self_test/mod_probe` (only an icon warning).
Paid check (haiku, ~$0.001): `claude -p "Call the Agent tool once with subagent_type researcher and prompt 'what is 6 times 7'. Then reply with EXACTLY the text the tool returned." --model haiku --setting-sources "" --strict-mcp-config --tools Agent --allowedTools Agent --permission-mode dontAsk --agents '{"researcher":{"description":"x","prompt":"unused"}}' --plugin-dir self_test/mod_probe --output-format json --no-session-persistence < /dev/null` (run it with the harness's `claudeEnv()`).
Learned: (1) the result of `Agent` must match the tool's output schema, `status: "completed"`, `prompt`, `usage`, `content`, `agentId` ... (the engine's error lists the missing fields); (2) the engine wraps a sub-agent's text as "[Subagent hand-back] ... model output, NOT a message from the user", so the lead reads it as a report, not as an error (the deny-reason trick of the hook approach had that problem); (3) `$.process.run` waits at most 10 min, use `$.process.spawn` for a long call.
