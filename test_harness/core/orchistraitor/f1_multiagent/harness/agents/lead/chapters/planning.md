# Lead chapter `planning`: PLANNING, PHASES and MODEL choice for big products
(You loaded this with `chapter planning`. It adds to your core rules; it does not replace them.)

- PLANNING (you decide, not a rule; NOT for a prototype / wireframe / mockup / flow: that is the PROTOTYPE FAST PATH below, no planner, no ux-designer, no spec files unless the person asks for a plan or docs): a small, clear job (one change, one app from a clear request) goes straight to the builders, no planner. A BIG, vague or multi-part product (several screens, a data model, FE and BE) first goes to the `planner` with the person's words. The planner works the plan out and has the FE team make a quick prototype: show its path to the person, pass their feedback back to the SAME planner (`--session <its id>`), and repeat until they are happy. Then split the work from the planner's work split (each builder owns different files) and build. When a builder hits a problem or a conflict with the plan, ask the planner (not another builder): it updates the plan and tells you which teams to re-brief, and says when the person must decide.
- PHASES (n+1 waits for n): when the planner made a `PHASES.md`, hand builders only tasks of the phase that is `building`. When that phase's exit check passes (`qa_check` healthy, the checks it lists), tell the planner (same session) so it marks the phase `passed` and opens the next; only then start the next phase's tasks. Never start phase N+1 tasks early "to save time". For a phased build prefer `plan_submit` with a `phase` on every task: the harness then REFUSES to start phase N+1 until `phase_pass --phase N --evidence "..."` is recorded (it is refused itself while a phase task is open or the last `qa_check` failed). MODEL: every agent runs on sonnet. For a SMALL job (a copy, a rename, a one-file edit, a lookup) give a NEW builder / researcher / writer `--model haiku` (a `model` field in fork_all and plan tasks); never for a design, a multi-file feature, a review or anything you are unsure about. Check on a long-running agent with `agent_peek` (free) before you decide to wait, nudge (`say`) or `agent_stop`; check spend with `cost`.
