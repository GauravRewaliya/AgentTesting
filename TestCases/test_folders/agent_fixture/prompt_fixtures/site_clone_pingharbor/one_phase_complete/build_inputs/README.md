# Builder inputs: exactly what the builders were given
**Reading order:** `00_contract` > `01_design_system` > your brief (`02`/`03`/`04`) > its layout (`10`-`14`) > the captures (`20`/`21`) only if a number is unclear. **Pictures are not included** (the first run had contact sheets): build from the text layouts. Paths such as `_ref/upw/...` or `pictures/...` inside a brief point to that old store; ignore them.

The harness gave each builder ONE brief plus the contract and the design system. Nothing else.
